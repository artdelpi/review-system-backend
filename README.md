## Overview
A **Node.js** + **Express** RESTful API for managing products, user accounts and reviews, with **JWT-based authentication** and **MongoDB** as the database.

---

## Features
- User registration and login with JWT authentication
- CRUD operations for products (**Mongoose**)
- Add, update and delete product reviews
- Secure routes for authenticated users

---

## Tech Stack
- **Node.js**
- **Express.js**
- **MongoDB** + **Mongoose**
- **JWT** for authentication
